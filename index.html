Auto Register Filler 个人本地版隐私说明

本插件用于在本机 Chrome 中自动识别表单、填充评论内容，并通过用户自己配置的 AI Provider 生成评论文案。

本地保存的数据

插件会使用 chrome.storage 在本机保存网站信息、姓名、邮箱、可选密码、AI Provider 配置、API Key、批量任务设置和本地运行结果。

AI 请求

插件不再请求项目自带后端。生成评论时，插件后台会直接请求你在设置页配置的 AI Provider，例如通义千问、DeepSeek、OpenRouter、OpenAI 或本机兼容接口。

不会使用的功能

当前个人版不包含支付、积分、远程用户账户、CSV 售卖、远程运行统计等功能。

安全提醒

API Key 会保存在本机浏览器扩展存储中。请不要把带有 API Key 的浏览器配置或插件目录分享给其他人。导出配置时，插件默认不会导出 API Key。
